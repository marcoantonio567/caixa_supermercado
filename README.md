# 🛒 Sistema de Supermercado Terminal / Terminal Supermarket System

## 🇧🇷 Português

### 📋 Descrição
Este é um sistema desenvolvido exclusivamente para **supermercados**, focado no controle de **estoque e vendas**. Toda a interação com o usuário acontece **diretamente no terminal**, sem a necessidade de interface gráfica, garantindo leveza, rapidez e eficiência para operações diárias.

### ⚙️ Funcionalidades
- ✅ Cadastro de produtos (código, nome, preço, quantidade em estoque)
- ✅ Controle de entrada e saída de mercadorias
- ✅ Registro de vendas com cálculo automático de total e troco
- ✅ Atualização automática do estoque após cada venda
- ✅ Geração de relatórios (produtos com baixo estoque, vendas do dia, faturamento)
- ✅ Persistência de dados (os dados são salvos em arquivos `.txt` ou `.json`)
- ✅ Interface 100% por linha de comando (CLI)

### 🚀 Como executar
```bash
python main.py
